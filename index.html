01 — Filosofia

Non è un framework

Brain Protocol non è un software da installare. È una convenzione: come organizzare file markdown perché qualsiasi agente AI possa leggerli, scriverci, e accumulare conoscenza nel tempo.

Il modello AI è sostituibile — oggi Claude, domani Gemini, dopodomani qualcosa che non esiste ancora. Il brain no. Il brain è tuo: è la tua conoscenza, le tue decisioni, i tuoi progetti. Portabile, leggibile, versionato.

Solo testo

Markdown puro. Nessun database, nessun formato proprietario. Apri con qualsiasi editor.

Git è il database

Ogni modifica è un commit. Branching, rollback, merge — gratis.

Frontmatter = schema

YAML in testa a ogni file. Tipo, data, tag, progetto. Struttura senza rigidità.

L'AI è sostituibile

Il brain sopravvive al cambio di LLM, di piattaforma, di tutto. È tuo per sempre.

02 — Architettura

La struttura delle directory

boot/ — Chi sei, chi è l'utente, cosa puoi fare
wiki/ — Entità strutturate: persone, aziende, progetti
diary/ — Log temporale: cosa è successo, quando, perché
todo/ — Task aperti con frontmatter e tag
inbox/ — Punto di passaggio per roba in entrata
public/ — File pubblicati, serviti via web
storage/ — Temporanei, cache, file non strutturati
.env — Credenziali (sempre gitignored)
# Ogni file .md ha un frontmatter YAML --- type: diary date: '2026-04-02' project: brainprotocol created_with: claude-sonnet tags: - meeting - decisioni - architettura --- # Il contenuto è markdown standard # Wiki-links: [[wiki/people/mario-rossi]]
03 — Getting started

Tre passi per iniziare

01

Clona il template

Un git clone e sei operativo. Apri la cartella con il tuo AI agent preferito — Claude Code, Cursor, Aider, qualsiasi cosa legga file.

02

Rispondi alle domande

L'onboarding interattivo ti chiede chi sei, cosa fai, come vuoi che l'agente si comporti. Genera automaticamente i file in boot/.

03

Usa il brain

Ogni sessione l'agente legge boot/, sa chi sei, accumula conoscenza in wiki/ e diary/. Il brain cresce con te.

04 — Compatibilità

Funziona con qualsiasi LLM

Claude Gemini GPT-4o Mistral Llama Cursor Aider Codex CLI

Se il tuo agent legge file markdown, è compatibile con Brain Protocol.
